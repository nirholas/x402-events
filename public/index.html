x402-events

Event search and on-sale checks over Ticketmaster Discovery — agents find real events and ticket windows

HTTP 402 · x402 v1 USDC on Base or Solana no API key

Routes

MethodPathPriceReturns
GET/search$0.003Search real events by keyword, city, country and start date
GET/onsale-check/{eventId}$0.002Current on-sale snapshot for one event, plus a delta against your cursor
GET/freeService metadata, live prices, and active payment rails
GET/healthfreeLiveness probe
GET/.well-known/x402freex402 discovery manifest

Call it

npm i x402-fetch viem

import { wrapFetchWithPayment } from "x402-fetch";
import { privateKeyToAccount } from "viem/accounts";

const fetchWithPay = wrapFetchWithPayment(
  fetch,
  privateKeyToAccount(process.env.PRIVATE_KEY)
);
const res = await fetchWithPay("http://localhost:4023/search");
console.log(await res.json());

An unpaid request answers 402 with the accepted rails; retry with the X-PAYMENT header and the artifact comes back in the body of that same request.
